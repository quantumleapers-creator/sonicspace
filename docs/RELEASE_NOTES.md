# Release notes

## Hackathon demo release
- Reframed the UI as an educational experience rather than a professional audio workstation.
- Added a beginner-friendly explanation that aims to communicate the idea within two minutes.
- Added explanations for surround sound, Dolby Atmos, HRTF and sound objects.
- Added everyday examples: films, games, music and mobile devices.
- Added an interactive three-step visitor journey.
- Added a room-only immersive fullscreen action.
- Added responsive Google Sans Flex typography and branded SVG icon.
- Kept a simplified spatial audio experiment using the Web Audio API.
